# V-Droid Engine 📱⚡

An Android virtualized OS container app built with modern Jetpack Compose and Kotlin, supporting root shell access simulation, multi-app switching, x86_64 architecture translation, and system configuration controls.

## 🚀 How to Download & Install the APK on Your Phone

### 📱 Option 1: Direct Download from GitHub Releases (Recommended)
When you export this repository to your GitHub account:
1. Open this repository on your mobile browser (Chrome/Edge/Firefox on your phone).
2. Go to the **[Releases](../../releases/latest)** page on GitHub (or tap the `v1.0.0` release tag).
3. Under **Assets**, tap **`V-Droid-Engine.apk`** to download the APK directly to your phone.
4. Tap the downloaded file on your phone and press **Install**! *(Ensure "Install from Unknown Sources" is enabled in phone settings if prompted)*.

---

### 📦 Option 2: Download Directly from Google AI Studio
If you are using Google AI Studio in your browser:
1. Tap the **Settings / Export** menu in the top right corner.
2. Select **"Generate APK"** or **"Export APK"**.
3. Download the compiled `.apk` file directly to your phone or computer.

---

### ⚙️ Option 3: Automatic Build via GitHub Actions
Every time you push changes to GitHub, GitHub Actions automatically builds a fresh APK:
1. Go to the **Actions** tab in your GitHub repository.
2. Click on the latest **"Build & Release Android APK"** workflow run.
3. Scroll down to **Artifacts** and tap **`V-Droid-Engine-APK`**.
4. Extract the ZIP file to get `V-Droid-Engine.apk` and install it on your device.

## ✨ Key Features Included in V-Droid Engine

- 🤖 **Virtual Android 9 (Pie) OS Container**: Authentic Android 9 navigation bar, notifications, and status bar layout.
- 🔓 **Pre-Rooted & Magisk Engine**: Active `su` binary execution, root terminal shell, SELinux policy controls, and root app granting.
- 📱 **Multi-App Switching & Dual Instance**: Run multiple virtual apps concurrently and switch between them with the Recent Apps menu.
- ⚙️ **x86_64 / ARM64 Translation Engine**: Binary architecture translation and virtual hardware parameter manager.
- 📁 **Virtual App Store & File Manager**: Preloaded virtual apps, file system browser, and APK package manager simulator.
