## ✨ Key Features Included in V-Droid Engine

- 🤖 **Virtual Android 9 (Pie) OS Container**: Authentic Android 9 navigation bar, notifications, and status bar layout.
- 🔓 **Pre-Rooted & Magisk Engine**: Active `su` binary execution, root terminal shell, SELinux policy controls, and root app granting.
- 📱 **Multi-App Switching & Dual Instance**: Run multiple virtual apps concurrently and switch between them with the Recent Apps menu.
- ⚙️ **x86_64 / ARM64 Translation Engine**: Binary architecture translation and virtual hardware parameter manager.
- 📁 **Virtual App Store & File Manager**: Preloaded virtual apps, file system browser, and APK package manager simulator.
